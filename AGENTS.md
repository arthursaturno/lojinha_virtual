# Regras Para Agentes

Antes de criar ou alterar codigo neste projeto, leia obrigatoriamente:

- `.codex/guides/architecture.md`
- `.codex/guides/feature-creation.md`
- `.codex/guides/code-generation-rules.md`
- `.codex/guides/design-system.md`
- `.codex/guides/api-guide.md`
- `.codex/guides/testing.md`
- `.codex/guides/final-validation.md`

Stack definido:

- Next.js App Router
- React
- TypeScript
- Clean Architecture
- MVVM com ViewModels/hooks controlando estado e intents da UI
- Modular por feature
- Supabase

Regra principal: nao implemente atalho fora da arquitetura. Se uma regra parecer excessiva para a tarefa, pare e explique o trade-off antes de escrever codigo.
